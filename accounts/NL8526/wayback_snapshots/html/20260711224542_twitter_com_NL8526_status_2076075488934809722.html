​最近 Minecraft 服务端核心 LuminolMC 宣布全面停更并彻底删库。起因是团队公开指控 CanvasMC 严重违反 GPL-3.0 开源协议，在偷偷搬运 Luminol 的跨区域移动修复、世界卸载等多处核心 API 代码时，故意把原作者的署名、来源和协议删得一干二净，反手贴上“Canvas 自有实现”的标签。

​最让人恶心的是被抓包后这群侵权者的嘴脸 🤮。他们在私下社区里毫无悔意，摆出一副极其傲慢和轻蔑的态度推诿扯皮：“这真的很微不足道”、“灵感借鉴不算偷”、“只是手动打补丁时不小心滑过去了”。
​原创团队向 GitHub 提交 DMCA 维权了整整一个月未果，每天还要被迫卷入这群无赖没有底线的无休止周旋中。核心维护者 EarthMe 最终在身体与精神的双重折磨下被彻底气绝，愤而删除了所有核心项目，注销账号彻底退网。

​开源圈的协作基石是尊重贡献者署名。如果劣币驱逐良币，纵容这种一边疯狂白嫖成果一边还要把原创者逼死的无赖，谁还愿意为爱发电做开源？！🤬
